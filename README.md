# Steve Park portfolio website

Static, responsive website prepared for GitHub Pages. It includes an industry-facing home page, a dedicated PhD thesis page for postdoctoral applications, a project page, and an `assets/` folder for figures.

## Preview locally

Open `index.html` in a browser, or serve this folder with any static web server.

## Publish with GitHub Pages

The files in this folder are prepared for `github.com/steve-seungwon-park/steve-seungwon-park.github.io`. Publish them to the repository's `main` branch. In repository settings, open **Pages** and select the `main` branch and `/ (root)` as the deployment source if Pages is not already enabled.

The expected site address is `https://steve-seungwon-park.github.io` after Pages finishes publishing.

## Before publishing

- Confirm the wording and technical descriptions, especially the in-progress Chapter 3 results and submitted manuscripts.
- Add paper links or PDFs if you want them available to visitors.
- The CV and personal phone number are not included in the public site.
